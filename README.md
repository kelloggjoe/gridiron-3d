# Gridiron 3D

A 3D football game built with three.js: full 11-on-11 offense and defense, momentum-based tackling, blocking and ball physics, a truck stick, jukes, spins, stiff arms and a hit stick.

## Play
Open `index.html` in a browser (needs internet for the three.js CDN). Keyboard required.

| Offense | Ball carrier | Defense |
|---|---|---|
| `1`–`9` pick play · `Space` snap | `Space` truck stick | `Space` hit stick / dive |
| `WASD` move · `Shift` sprint | `F` juke · `R` spin | `F` jump / swat / shed |
| `1`–`5` throw (tap = bullet, hold = lob) | `E` stiff arm | `Tab` switch player |

`P` pause · `H` controls
